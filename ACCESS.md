# Access and usage

This repository is public. Reading, downloading, and cloning it requires no invitation or GitHub account. Each operator still needs their own authorized access to the connected services.

For the original GTME materials, you may download, run, and modify the skills for your own personal or internal business use. No separate access request or agreement is required for that use. Other rights are reserved by The GTM Engineering Company. This follows the usage permission used for the company's public HubSpot skill; public visibility does not by itself grant a general open-source license.

The `skills/track-contact-job-changes/` package is distributed under its included MIT license. That license governs that package and is not restricted by the paragraph above. See NOTICE.md for attribution.

Contractors only need a GitHub invitation if they will contribute directly to the repository. A maintainer can assign named accounts the appropriate repository role. Downloading the skill never grants access to a client's CRM, documents, or campaigns.

Notion setup pages have their own sharing permissions. Share the intended page with its recipient; do not assume public GitHub access makes an internal Notion workspace public.
