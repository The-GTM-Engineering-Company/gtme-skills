# Contributing

Keep each SKILL.md concise and link to the references needed for a particular task. Preserve existing authorization, identity checks, evidence, and verification rules when changing a workflow.

Use a branch and pull request for updates. Describe the behavior changed and validation performed. Run `python3 scripts/validate.py` from the repository root.

Use invented examples. Never commit client identifiers, source documents, contacts, CRM payloads, credentials, browser profiles, campaigns, runtime files, or private correspondence. Review the staged diff and all newly tracked files before publishing. Keep source attribution and applicable licenses.

Documentation validation does not replace verifying a customer's current tool access and data model. CRM writes and campaign changes require that customer's scoped authorization and verification in their system.
