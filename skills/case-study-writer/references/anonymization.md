# Anonymized case studies

Use an anonymized version only for material the operator is entitled to share. Removing a name does not authorize disclosure of confidential facts.

Replace client/product/person names with suitably broad descriptors. Remove domains, direct source links, account IDs, private screenshots, customer rosters, and distinctive quotes that identify the client. Do not retain an agency hyperlink if the brief calls for full anonymization of both parties.

Review combinations: a narrow niche plus exact city plus team size can identify someone without a name. Keep only the detail needed to make the result useful.

Preserve factual meaning. If an exact metric is identifying, omit it or use an explicitly approved range/rounding and label that treatment; never silently change a number. Keep the exact value and its treatment in the private fact-source map. Common tool names can remain if the combination does not identify the client.

Search the complete output, including links, filenames, titles, quote attributions, alt text, and metadata, for disallowed names and domains. Then perform a human-style re-identification read; a zero-hit search is not enough. Describe unresolved disclosure questions privately and keep the draft unpublished until resolved.
