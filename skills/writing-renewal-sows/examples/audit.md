# Synthetic audit example

| Commitment | Evidence | Status | Renewal treatment |
| --- | --- | --- | --- |
| Deliver a documented lead-routing workflow | Approved workflow and handoff recording | DELIVERED | Scope ongoing support only if requested |
| Train two teams | One training completed; second session deferred | PARTIAL | Carry over the second session |
| Launch a scoring model | Build file exists; later recap says launch paused | IN FLIGHT if active work is evidenced, otherwise PARTIAL | Resolve launch dependency |
| Produce an adoption report | Required usage source is inaccessible | UNVERIFIED | Obtain evidence before asserting completion or failure |

All entries are invented. The table demonstrates status logic, not an actual engagement.
